# 📚 Library Management System (SQL + MySQL)

A database project simulating a Library Management System built with MySQL. It demonstrates core DBMS concepts like schema design, relationships, constraints, triggers, and useful query logic.

## 📁 Project Structure
- `schema.sql`: All CREATE TABLE statements
- `data.sql`: Dummy data to populate the database
- `queries.sql`: Select queries to interact with the system
- `triggers.sql`: Trigger to auto-calculate late return fines
- `extras.sql`: Optional additions like book reservation table.

## ✅ Features
- Book borrowing and return system
- Author-book and borrower-book relationships
- Late return fine with automatic calculation
- Fine payment tracking
- Realistic queries for library operations

## 💻 Tech Stack
- SQL (MySQL dialect)
- MySQL Workbench / Notepad++ 

## 📦 How to Run
1. Import `schema.sql` into your MySQL DB
2. Run `data.sql` to insert sample records
3. Try queries in `queries.sql`
4. Check out the auto-trigger in `triggers.sql`

## 📊 What You'll Learn
- Relational schema design
- JOINs, aggregations, constraints
- Triggers and automation in SQL
- Real-world query logic

## 🧠 Possible Add-ons
- Book reservations table
- Fine payment history
